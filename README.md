# vCISO Application

Virtual CISO platform — security posture dashboard, compliance 
reporting, asset inventory, and VA/BA records management.

## Structure
- `frontend/` — React + TypeScript + Tailwind CSS
- `backend/` — Python FastAPI (upcoming)
- `docs/` — Architecture decisions and feature documentation
- `.claude/` — Claude Code project configuration (agents, commands, skills)
